# Yuva Intern - Week 1: Python for Machine Learning & Data Preprocessing

## Project Overview
This project was completed as part of the Yuva Intern Week 1 task. It demonstrates basic Python programming and data preprocessing techniques used in Machine Learning.

## Objectives
- Understand Python libraries used in Machine Learning.
- Load and inspect data using Pandas.
- Identify and handle missing values.
- Detect and remove duplicate records.
- Encode categorical data.
- Scale numerical features.
- Perform basic analysis and visualization.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Files
- `Week1_Data_Preprocessing.ipynb` - Main Jupyter Notebook containing the complete work.
- `student_performance.csv` - Dataset used for the task.
- `requirements.txt` - Required Python libraries.

## Preprocessing Steps
1. Imported required Python libraries.
2. Loaded the CSV dataset using Pandas.
3. Inspected rows, columns, data types, and statistics.
4. Checked for missing values.
5. Filled missing numeric values using the median.
6. Detected and removed duplicate records.
7. Encoded categorical columns.
8. Standardized numerical score features.
9. Calculated basic statistics.
10. Created simple visualizations.

## How to Run
1. Install Python 3.
2. Install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```
3. Open the notebook:
   ```bash
   jupyter notebook Week1_Data_Preprocessing.ipynb
   ```
4. Run all cells from top to bottom.
